# Meu Primeiro Repositório

Entregável do exercício **ia-1.1 — Seu Primeiro Repositório**, da disciplina
Agentes de IA, turma IA-2026-01.

Este repositório registra a prática de criar um histórico Git e disponibilizar
um README em um repositório público no GitHub.

## Histórico da prática

O primeiro commit adiciona a apresentação do exercício. O segundo acrescenta
esta seção, permitindo observar a evolução do arquivo no histórico Git.

Os comandos foram automatizados pelo agente e executados em Docker. A reflexão
do aluno e os boletins de validação são mantidos fora deste repositório.
